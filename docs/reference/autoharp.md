# autoharp: Semi-Automatic Grading of R and Rmd Scripts

The autoharp package provides functions for running and analysing R
script/Rmd submissions from students.

## Main functions are

1.  [`populate_soln_env`](https://github.com/namanlab/autoharp/reference/populate_soln_env.md)

2.  [`render_one`](https://github.com/namanlab/autoharp/reference/render_one.md)

3.  [`TreeHarp`](https://github.com/namanlab/autoharp/reference/TreeHarp-class.md)

The user manuals can be found at <https://namanlab.github.io/autoharp/>
